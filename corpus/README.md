# Test corpus

## `fixtures/`

Synthetic EPUBs generated by `scripts/build-fixtures.ts` and committed. They encode
the *structures* that break real readers — books with no spread metadata, explicit
`page-spread-*` properties, RTL progression, mixed viewports, pre-composed spread
pages, missing viewports, and media overlays — without shipping anyone's
copyrighted artwork.

## `local/`

**Gitignored.** Real, in-copyright books used during development. The reference
book is `amelia-bedelia-birds.epub` (HarperCollins, ISBN 9780062334268), which is
the canonical target for fixed-layout + word-level read-along.

Tests that need it skip themselves when it is absent, so CI stays green without it.
